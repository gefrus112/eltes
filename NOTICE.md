# Third-party assets

- **Lucide icons** — ISC License. Vector paths are embedded in `assets/js/icons.js`. https://lucide.dev
- **Inter** — SIL Open Font License 1.1. Variable latin subset in `assets/fonts/inter-latin.woff2`.
- **JetBrains Mono** — SIL Open Font License 1.1. Variable latin subset in `assets/fonts/jetbrains-mono-latin.woff2`.
- **Simple Icons** — CC0 1.0 Universal. Provider mark paths are embedded in `assets/js/brands.js`; the
  OpenAI, Z.ai/GLM, xAI/Grok and Groq marks are drawn in-house because Simple Icons has no entry.
- **Eltes green-cloud mark** — original artwork for this project (`assets/img/eltes-cloud.svg`).
  PNG icons and the Windows `.ico` are rasterised from that SVG; no third-party image assets are used.

Model names and provider marks are used descriptively. Eltes is not affiliated with OpenAI, Anthropic,
Google, Z.ai/Zhipu, DeepSeek, xAI, Alibaba/Qwen, Mistral, Meta, Groq or OpenRouter.
