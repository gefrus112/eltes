Optional Vercel/local backend

Use a backend you control for provider key checks and hosted-model requests. A key is sent over HTTPS with each request and is not stored by the Eltes function code. The backend operator and platform still process it; use only a backend you trust. Leave blank for direct browser-to-provider requests.

Proxy off — hosted requests go directly from this browser to the provider.
GitHub Pages is static and does not run this backend. See backend deployment docs.

Bring your own key

Keys are saved in this browser's local storage. By default, they go directly from the browser to your selected provider. If you set a backend above, requests and the key test go through that backend. Eltes does not decide free-tier eligibility or provider billing.

Web search

Optional live web search with numbered source links. Eltes calls a search API through your configured backend, using your own search key; the key is sent with that request only and is never stored by the backend. Search providers charge under their own terms.

Custom endpoint

Connect an already-running Ollama, LM Studio, vLLM, LiteLLM, or other OpenAI-compatible server at /chat/completions. This connects to an inference endpoint; it does not train a model. Configure its CORS allowlist for this page's origin.

Requests are sent from your browser; localhost endpoints must allow CORS.
