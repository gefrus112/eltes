Here's a dependency-free version. The timer is cleared on cleanup, so fast re-renders never fire a stale callback.

useDebounce.ts
export function useDebounce(value, delay) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    // cleanup cancels the pending update
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

The returned value only changes after the delay

The whole workspace is static files. The Windows launcher starts a tiny local server and opens your browser — no installer, no registry, no admin rights, no background service.

Windows v3.2.0 · portable

Eltes for Windows

Unzip anywhere and double-click eltes.bat. It finds Python or Node, serves the folder on 127.0.0.1:4173 and opens the workspace.

  • Includes the launcher and the full site
  • Optional Start-menu shortcut with --shortcut
  • Needs Windows 10/11 and Python 3 or Node 18+
  • Runs offline; keys stay in your browser
