Agent mode

It calls tools.
It doesn't pretend to.

Eltes runs a real tool loop through your provider: the model requests a tool, the browser executes it, the result goes back into the conversation. Every call is timed and visible.

  • Local tools — calculate maths, read the clock, search your own chat history.
  • Provider-native — OpenAI tool calls and Anthropic tool_use, streamed.
  • Interruptible — stop mid-loop and keep every token already received.

Downloads

Run Eltes
from your desktop.

Install Eltes on a Chromebook as a standalone Chrome app, or download the portable Windows launcher. The Chromebook install uses the secure hosted PWA; Windows can run locally with no installer, registry changes, or admin rights.

Windows v3.3.0 · portable

Eltes for Windows

Unzip anywhere and double-click eltes.bat. Node.js runs the local API when available; otherwise Python serves static files. The workspace opens on 127.0.0.1:4173.

  • Includes the launcher and the full site
  • Optional Start-menu shortcut with --shortcut
  • Needs Windows 10/11 and Python 3 or Node 18+
  • CAI works offline; keys stay in your browser
Download eltes-windows.zip
Zip · includes eltes.bat, Start-Eltes.ps1 and the site
macOS · Linux

Serve the same files

Clone the repository and run npm install && npm start to serve the site with the optional local API. A static server such as Python works too, but does not run key checks or the proxy.

npm start
Chromebook · ChromeOS

Install Eltes as a Chromebook app

Open Eltes in Chrome, then choose Install Eltes from the address bar or ⋮ → Cast, save, and share → Install page as app. It opens in its own window and appears in your Launcher.

Open workspace

The Windows launcher is reviewable text — read it before running. Its optional terminal runner is off by default, requires Node.js, and asks you to approve each command. The Chromebook PWA itself cannot access a terminal; see the local runner setup in the docs if you want approved commands on your own device.
