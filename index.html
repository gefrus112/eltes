WebGPU is a browser API that exposes modern GPU features — compute shaders and rendering — to JavaScript 12. It ships in current Chrome, Edge and Safari releases, with Firefox support rolling out behind flags 3. Check the browser support table before relying on it in production 4.

Eltes Lab

A model you train
in your own tab.

Not a demo script. A real character-level network — embeddings, a hidden layer, softmax — trained by backpropagation and Adam in plain JavaScript, then saved to this browser.

Real gradients

51,245 weights, hand-written backprop, dropout, weight decay, gradient clipping and Adam with bias correction. The loss falls because the maths ran.

Curves, not claims

Training and held-out validation loss are drawn live, with the best validation point marked. On a corpus this small the dashed line turns up — overfitting, shown rather than hidden.

Yours after one save

The checkpoint lives in localStorage. Eltes Lab-1 then appears in the workspace picker and continues your text — honestly labelled, no key, no upload.

Agent mode

It calls tools.
It doesn't pretend to.

Eltes runs a real tool loop: the model requests a tool, the browser executes it, the result goes back into the conversation. With Eltes CAI-1 there is no model to ask — a deterministic planner picks the tools itself. Every call is timed and visible either way.

  • Eight tools — arithmetic, unit and temperature conversion, percentages, calendar maths, the clock, your own chat history, the glossary, and cited web search with your own key.
  • Works with no key — Agent mode is on by default. On CAI-1 the planner runs six of those tools in the tab, so nothing is sent anywhere.
  • Provider-native — OpenAI tool calls and Anthropic tool_use, streamed, up to four rounds.
  • Interruptible — stop mid-loop and keep every token already received.
