Agent mode

It calls tools.
It doesn't pretend to.

Eltes runs a real tool loop through your provider: the model requests a tool, the browser executes it, the result goes back into the conversation. Every call is timed and visible.

  • Local tools — calculate maths, read the clock, search your own chat history.
  • Provider-native — OpenAI tool calls and Anthropic tool_use, streamed.
  • Interruptible — stop mid-loop and keep every token already received.

Unzip anywhere and double-click eltes.bat. It finds Python or Node, serves the folder on 127.0.0.1:4173 and opens the workspace.

What an install actually grants

Installing Eltes in Chrome or on a Chromebook makes a shortcut around the same sandboxed page. It is not a native program, and a web page has no API that can run commands on your machine.

It can

  • Open in its own window and load from cache once visited
  • Read its own chats, settings and saved keys in this browser profile
  • Send requests to the provider or proxy you configure
  • Write an export to your Downloads folder when you ask

It cannot

  • Run shell commands or start processes — no page gets that API
  • Open the Linux terminal or read ChromeOS system files
  • Read files from your disk unless you pick them in a dialog
  • See other tabs, other sites, or anything outside its origin

eltes.bat is Windows-only and separate: it is a readable text file that starts a local static server as your own user — it does not run on a Chromebook, and it never asks for admin rights. Keys still live in this browser profile, which is why anyone with access to that profile can read them.

The launcher is a reviewable text file — read it before you run it. It binds to localhost and only serves files from the folder you unzipped; it does not run the optional API backend.
