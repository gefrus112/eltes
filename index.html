Write a tiny debounce hook for React, then explain the cleanup.

Here's a dependency-free version. The timer is cleared on cleanup, so fast re-renders never fire a stale callback.

useDebounce.js
export function useDebounce(value, delay) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    // cleanup cancels the pending update
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

The returned function is recreated only when value or delay changes

Agent mode

It doesn't just chat.
It does the work.

Eltes runs a real tool loop: read the codebase, find the cause, make the edit and explain what changed. Every step is visible and interruptible.

  • Streamed tool calls — see what the agent reads, greps and writes, as it happens.
  • Stop at any token — cancel a run without losing the partial answer.
  • Bring your own endpoint — any OpenAI-compatible base URL works.
