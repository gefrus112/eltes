v3.16.0 Latest release

The welcome email is real, and it is yours.

Create a profile and Welcome to Eltes AI Workspace arrives in the inbox — sent by the server on your own machine through your own free provider account. Resend, Brevo and any SMTP mailbox are supported. With nothing configured, the message is written to a real .eml outbox instead of pretending to send.

  • Free, no card — Resend gives 3,000 messages a month, Brevo 300 a day, and an SMTP mailbox costs whatever your host already charges. One environment variable each.
  • No middle man — the browser posts to /api/email/welcome on the same origin. Eltes has no mail server, no list and no tracking pixel; the address never leaves your provider call.
  • Bounces count — a 5xx at RCPT TO is a hard bounce in the same request, provider webhooks are normalised, and hard bounces are remembered so the next send never touches the network.
  • Honest states — Sent via resend, Saved to the local outbox, No mail server on this host on the static site, and the provider's own error text when it refuses.

v3.16.0 Desktop · harness

Eltes becomes a desktop app.

A real harness in desktop/ builds a Windows installer and a portable .exe, macOS disk images for Apple silicon and Intel, and a Linux AppImage and .deb. Each one is the same site in a native window, with the local server, Studio, the terminal and Eltes Lab already inside — no Node installed, no tabs, no second app to keep in sync.

  • Self-contained — the shell starts the bundled server with its own binary (ELECTRON_RUN_AS_NODE) on a free loopback port, then loads the workspace from it. Nothing to install first.
  • Hardened window — context isolation, no node integration, sandboxed renderer, five bridge calls, and navigation locked to the app's origin. Other links open in your browser.
  • Fails loudly — if the server will not start, a recovery screen names the error, the data folder and the log, with a Try again button instead of a blank window.
  • Built where it runs — GitHub Actions builds Windows on Windows, macOS on both Apple silicon and Intel runners, Linux on Ubuntu, and attaches every installer to the tagged release.

v3.14.0 Lab · training

Train the model yourself, then read the curve.

Lab is a real neural network you train in the tab: 51,245 weights, hand-written backpropagation, Adam, live training and validation curves, and a checkpoint in localStorage. It is a character-level model, and the page is honest about what that means.

  • It actually learns — the loss falls because the weights change, not because a script prints a nicer number. A seeded run is reproducible; the same setup draws the same curve.
  • The honest curve — validation loss on held-out text is drawn next to training loss, with the best point marked. On a corpus this small it turns up, and the page says why.
  • A pass-mark test — the memorisation demo trains on one paragraph until the loss reaches zero, then recites it back; match is measured character by character, usually above 90%.
  • Yours, on-device — save the model and Eltes Lab-1 appears in the workspace picker. It quotes a continuation and states its limits; no key, no upload, no network request.

v3.13.0 Embers · pointer

The empty chat now answers your pointer.

Move the mouse across the new-chat screen and a hearth of orange embers follows it: a warm glow, eight orbiting sparks, wispy updraughts and a slow rain of embers rising from the composer. It is drawn on one canvas — no libraries, no images.

  • Speed is heat — move faster and the glow brightens, sparks fly and the trails lengthen; stop and it settles to a gentle burn.
  • Click to stoke it — a click throws a burst of sparks and embers.
  • Only where it belongs — the effect fades out the moment a conversation starts, and pauses with the tab.
  • Cheap and respectful — 30 fps, DPR capped at 1.75, a still frame under reduced motion (system or Settings → Reduce motion).

v3.8.0 Studio

Files, editor, preview, terminal — one window.

Eltes Studio is a coding workspace served next to the app. A real shell runs in .studio/, every HTML file previews at /preview/ with its CSS and scripts intact, and saving reloads the pane.

  • Any HTML previews — the pane follows the file you open, not a fixed index.
  • Auto-save, auto-reload — edits and build output both refresh the preview.
  • Real commands — ls, node, npm run build, 60-second limit, Ctrl+C to stop.
  • Safe by default — token-protected routes confined to .studio/.

v3.7.1 Interface

Grey chat, not blue.

The workspace shipped Graphite: neutral grey shell, bubbles, accents and send button, with Midnight blue as the second theme. v3.12 replaced Midnight with Obsidian black.

  • Grey by default — data-theme="grey" on the app shell.
  • Tokenised — accents, panels and gradients come from CSS variables.
  • Persisted — the choice lives in eltes.settings.v1 and updates the browser chrome colour.
  • Reversible — switch between Graphite and Obsidian in Settings → General, no reload.
